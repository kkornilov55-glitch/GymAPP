# Workout Tracker REST API

Серверная часть (Backend) для приложения по отслеживанию тренировок. Проект представляет собой RESTful API для управления дневником тренировок, агрегации статистики и работы с пользовательскими показателями (силовые упражнения и тренировки с собственным весом).

## О проекте
Цель проекта — создание масштабируемого и надежного Backend-приложения на базе **Spring Boot** с применением микросервисных паттернов (в рамках монолита). API спроектировано для обслуживания любых клиентских платформ (Web, Android, iOS).

## Дорожная карта (Roadmap)

### Фаза 1: Фундамент REST API
- [ ] Инициализация проекта на **Spring Boot** (Spring Web).
- [ ] Проектирование и реализация базовых REST контроллеров (`/exercises`, `/workouts`).
- [ ] Внедрение **DTO (Data Transfer Objects)** для изоляции внутреннего представления данных от сетевого обмена.
- [ ] Настройка **Swagger/OpenAPI** для автоматической генерации интерактивной документации API.
- [ ] Реализация глобального обработчика исключений (`@ControllerAdvice`) для стандартизации ответов об ошибках.

### Фаза 2: База данных и ORM
- [ ] Подключение **PostgreSQL** в качестве основной реляционной СУБД.
- [ ] Интеграция **Spring Data JPA (Hibernate)** для маппинга сущностей (Entity).
- [ ] Настройка **Liquibase** (или Flyway) для версионирования и миграций базы данных.
- [ ] Автоматическое заполнение БД базовым справочником упражнений и мышечных групп при инициализации схемы (Initial Seed).
- [ ] Реализация CRUD-операций для пользовательских тренировок и кастомных упражнений.

### Фаза 3: Бизнес-логика и Аналитика
- [ ] Разработка сервисного слоя для валидации сложной бизнес-логики.
- [ ] Создание Endpoint'ов для аналитики:
  - Вычисление личных рекордов (PR - Personal Records).
  - Агрегация тренировочного объема (тоннаж/время) за выбранный период.
- [ ] Оптимизация сложных выборок с использованием JPQL и EntityGraph.

### Фаза 4: Умные функции и Фоновые задачи
- [ ] Создание системы планирования тренировок (Workout Schedules).
- [ ] Интеграция **Spring Scheduling** (`@Scheduled`) для запуска регулярных фоновых проверок расписания.
- [ ] Интеграция с **Firebase Cloud Messaging (FCM)** для отправки push-уведомлений клиентам о запланированных тренировках.

### Фаза 5: Безопасность и Развертывание
- [ ] Внедрение **Spring Security** и настройка **JWT (JSON Web Tokens)** для аутентификации и авторизации пользователей.
- [ ] Разграничение доступа к данным (каждый пользователь имеет доступ только к своему дневнику).
- [ ] Упаковка приложения в **Docker**-контейнер.
- [ ] Написание `docker-compose.yml` для быстрого локального развертывания связки "Приложение + БД".

## Стек технологий
* **Язык:** Java 21+
* **Фреймворк:** Spring Boot 3 (Web, Data JPA, Security)
* **База данных:** PostgreSQL, Liquibase
* **API Документация:** Swagger (Springdoc OpenAPI)
* **Инструменты:** Maven/Gradle, Docker, Firebase (FCM)
