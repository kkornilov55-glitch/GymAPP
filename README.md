# Трекер тренировок (Workout Tracker)

Консольное (в перспективе — мобильное) приложение для удобного ведения дневника тренировок. Проект ориентирован на отслеживание силовых показателей и упражнений с собственным весом (calisthenics).

## Цель проекта
Создать минималистичный и удобный инструмент для записи подходов (на повторения и на время), отслеживания личного прогресса и организации тренировочного процесса без лишнего визуального шума.

## Дорожная карта разработки (Roadmap)

Проект разделен на логические этапы для последовательного внедрения функционала.

### Фаза 1: Консольное ядро (Java Core)
- [x] Разработка базовой архитектуры ООП (классы упражнений, дневник).
- [x] Безопасный консольный ввод и обработка исключений.
- [ ] **Справочник упражнений:** Создание каталога базовых групп мышц и сохранение кастомных упражнений, введенных пользователем.
- [ ] **Сохранение данных:** Интеграция записи истории тренировок в локальный файл (формат JSON).

### Фаза 2: Мобильный переезд (Android)
- [ ] Создание базового графического интерфейса под Android (Material Design).
- [ ] Интеграция консольной бизнес-логики в мобильное приложение.
- [ ] Миграция сохранения данных с локального JSON на базу данных **Room**.

### Фаза 3: Аналитика и прогресс
- [ ] **Отслеживание показателей:** Система анализа прогресса для конкретных сохраненных упражнений (например, рост максимума в подтягиваниях).
- [ ] **Визуализация:** Построение графиков тренировочного объема.
- [ ] **Личные рекорды:** Достижения и фиксация лучших результатов (PR - Personal Records).

### Фаза 4: Умные функции и экосистема
- [ ] **Расписание:** Настройка тренировочных дней.
- [ ] **Напоминания:** Локальные Push-уведомления по расписанию пользователя.
- [ ] *[В планах]* **Wear OS:** Приложение-компаньон для смарт-часов для запуска таймеров отдыха и отбивки подходов прямо с запястья.

## Стек технологий
* **Язык:** Java 
* **Архитектура:** ООП (Наследование, Полиморфизм, Интерфейсы)
* *(Будущее)* **Android SDK:** Room, WorkManager / AlarmManager
