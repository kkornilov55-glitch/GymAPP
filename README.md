# Дневник тренировок (Telegram bot)

Телеграм бот для отслеживания прогресса тренировок (в основном с собственным весом).
Пишу проект для систематизации собственных тренировок, изучения программирования на Java на практике, работы с Spring Boot, REST API и проектирования баз данных.

---

## Стек технологий
- **Язык:** Java 26
- **Фреймворки:** Spring Boot
- **Интерфейс:** Telegram Bot API (long-polling)
- **База данных:** Пока сохранение данных не реализовано, однако запланирована реализация на PostgreSQL

## Текущий статус проекта
На данный момент реализован каркас бота и интерфейс взаимодействия с пользователем:
- [x] Настроено подключение к Telegram API.
- [x] Реализована машина состояний для ведения пошагового диалога с пользователем.
- [x] Бот умеет собирать данные об упражнении (тип, название, группа мышц, подходы и повторения/время выполнения).

## Дальнейший план разработки
- [ ] Сохранять в оперативной памяти данные об упражнении и о тренировке в целом.
- [ ] Спроектировать базу данных для хранения пользователей и их тренировок.
